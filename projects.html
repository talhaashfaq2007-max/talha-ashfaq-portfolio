CareerLens — Resume Analyzer

A resume-analysis prototype that extracts selectable text from a PDF and compares supported skill keywords with a target job description.

  • PDF upload and text extraction with PyPDF
  • Rule-based skill matching and missing-skill detection
  • Estimated keyword compatibility score
  • Improvement suggestions and text report export
PythonFastAPIPyPDFJavaScript

Current limitation: scanned image PDFs are not supported; analysis is keyword-based, not an official ATS score or AI assessment. The local API must be running.
