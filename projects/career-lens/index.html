Understand your resume match.

Compare the skills mentioned in a resume with those in a job description. CareerLens is a simple keyword-matching prototype, not an official ATS or AI evaluation.

Choose a mode: Paste resume text for a fully browser-based demo, or upload a selectable-text PDF when the optional local Python API is running. No resume content is sent to an external server by the text mode.

Local Python API setup

From the projects/career-lens/backend folder:

python -m venv .venv
# activate the environment
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

Then serve the portfolio locally using python -m http.server 5500 and visit this page. PDF extraction requires selectable text; scanned images are not supported.
